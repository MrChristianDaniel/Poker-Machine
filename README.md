Upon running .py file user is prompted to enter either 'user' or 'test' to indicate mode

In 'user' mode the user is prompted to enter a space character ' ' to play a single turn on the machine. The game keeps a record of the total amount gained/lost and various other stats for the session. The user can terminate the session by entering 'q'.

In 'test' mode the user is prompted to enter a desired number of iterations for the game to be run over. Entering a number (x) will automatically play the slot machine x number of times. After all the plays the user can then view the session statistics including Hit Rate and Return To Player.
